# Chicken site - breed page list (25 Sep 2026)

Follows 11-backyard-chickens.md and 12-chicken-food-pages.md.
Semrush US, seed "chicken breeds", include filter "chicken", top 500 keywords
(down to ~600-700/mo). The whole "chicken" family under this seed: 35,002 keywords,
2,555,020 searches/month, avg KD 19.

**Caveat:** the "chicken" filter only catches searches that contain the word "chicken".
Breeds people search by bare name ("buff orpington", "black copper marans",
"easter egger", "leghorn", "olive egger") are under-counted here. Those need one more
Semrush pass (seeds: orpington, marans, leghorn, egger, silkie) when the browser is back.
From yardroost's data: easter egger chicken 22,200/KD 30, sapphire gem chicken 18,100/KD 17.

## Breed data table fields (for the robot)

origin, class (APA), size (standard/bantam), weight hen/rooster, eggs per year, egg colour,
egg size, temperament, broodiness, cold hardy, heat tolerant, comb type, feather colours
(varieties), lifespan, good for beginners (y/n), good for kids, confinement tolerance,
meat/egg/dual/ornamental, rarity, price range for chicks.
Sources: APA Standard of Perfection (breed class facts), Livestock Conservancy
(heritage breeds), university extension pages. Photos: must be own or licensed.
